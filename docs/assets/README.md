# Assets the family drops in themselves

- `papa.png` — KING PAPA's face, for the Star Vault's secret boss. A square
  photo around 512px works best; the game clips it into a circle either way.
  `.jpg`, `.jpeg` and `.webp` work too — the loader tries each spelling in
  turn, so upload whatever you already have without renaming or converting.
  Until the file exists the boss wears a gold "?" medallion saying where to
  put it. Only the family ever adds this file: nothing in this repo commits
  a real photograph on anyone's behalf.
- `pilots/` — illustrated pilot portraits (see its own README).
